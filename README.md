## 📅 모두의 공강 
삼육대학교 학생들을 위한 공강 시간 공유 및 시간표 관리 웹 서비스
모두의 공강은 학교 학생들이 무의미하게 사용되는 공강 시간을 의미있게 보낼 수 있게 하는 통합 게시판 플랫폼입니다.

## 🚀 핵심 기능
- 카테고리별 게시판 기능: 밥, 스터티, 운동 등 다양한 카테고리별 게시판에서 모집 글 작성,수정, 삭제 기능
- 그룹 공강 확인: 모집글을 통해 그룹을 생성하고 그룹내에서 채팅을 통해 빠른 모임을 결성
- Spring Security(보안 기능): 학생들사이에서의 보안성을 위하여 스프링시큐리티 라이브러리를 이용하여 보안성 강화
- 기능별 단위, 통합 테스트: 그룹, 게시판, 유저 등 핵심 기능들을 단위, 통합적으로 테스트를 거쳐 완성도를 높임

## 🛠 Tech Stack
Backend
- Framework: Spring Boot 
- Language: Java 
- Database: MySQL
- ORM: Spring Data JPA / Hibernate
- Security: Spring Security (인증 및 인가 관리)

## Frontend
- Template Engine: Thymeleaf 
- Styling: CSS3
- 프론트 엔드쪽 개발이 미완성 추후 개발 중


## 💡 주요 고민 및 해결 경험
- DB 쿼리 최적화: JPA를 사용하면서 발생하는 치명적인 문제 N+1문제 발생
  >> 목록 조회와 같이 연관 데이터가 즉시 필요한 경우에는 Fetch Join을 적용한 JPQL을 직접 작성 
- 테스트 시나리오 설계 및 테스트 코드 작성: 테스트 코드의 형식 이해도 부족, 다양한 테스트 시나리오를 테스트 코드에 적용하는 과정에서 문제 발생
  테스트 코드 작성의 진입 장벽을 낮추기 위해, 스타일인 Given(준비/상황)-When(실행)-Then(검증)의 3단계를 팀 내 필수 컨벤션으로 확립
